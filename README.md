# DoDo 長者及照顧者支援

[開啟免費網站](https://lihunglam14-commits.github.io/dodo-care/)

第一題提供「津貼或減輕開支」及「活動及認識朋友」。選活動後，先選屋邨及一間中心，再按月份、主題或關鍵字找活動。支援大字、中英文、電話、地圖及離線使用。

2026-11-01從胡忠中心官網11月月刊、10–12月課程季刊及電影海報補回83項，胡忠合共85項活動／班組。包括語文、書畫、唱歌、運動、手機課程、桌遊、剪髮、護老者活動及電影候補。保留會員／學員費用、資格、材料、停課及報名日期；相同報名安排集中顯示。已開班、有餘額才接受報名及候補安排均有註明，不保證即時有位。

富泰、信義健頤、王木豐及信義尊長會仍未有可核實的當期逐項時間表；其他中心亦不宣稱活動已全部齊全。請向中心確認實際資格、費用、報名、名額及場地。DoDo並非政府或服務機構網站。

活動清單以單欄概覽顯示名稱、日期、收費及簡短資格；介紹、時間、地點及報名方法按「詳情及報名」查看。相同報名安排只列一次，截止及未開放日期仍直接顯示。活動資料及數量保持原樣。

本分支只存放公開網站靜態產物，不包含私人Excel或開發原始檔。
