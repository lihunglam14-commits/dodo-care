此版本無須登入，雲端使用統計已關閉，也不會向 `/api/analytics/events` 送出請求。試用期間如需回饋，請由同事直接收集，不會從此網站自動取得長者的使用資料。

2026-10-17 更新：問答先選附近地區、再選屋邨或地點，也可直接搜尋。9 組生活地區只作導航，全部 188 個地點可從完整名單或搜尋選取；服務按實際屋邨及各自的官方服務範圍配對，不把個案分區套用到所有活動。結果頁可查看所選屋邨各項服務的所屬中心。

主辦原刊確認樂元聚於2026年7月31日搬至置樂花園地下37–39號舖，舊臨時地址停止服務；新址與地圖已更新。12月一般活動11月16日截止、17日抽籤；活動費、會員年費及指定車資分開列明，月度活動不套用中心地圖。部分活動、政策及服務資料已於 10 月 17 日核對，核對範圍、未確認費用及名額仍逐項標示，不代表所有資料均已全面重核。

同日政府原文覆核：按社署四份綜合家庭服務中心服務範圍表，現有158個地點的明確配對（今輪新增嘉和里配東屯門及8個政府完整地址配西屯門，附社署與地址證據）；弦海因兩份官方表重疊，保留兩個候選中心並標示待確認，其餘29個地點仍待查。加入公營醫療全年收費上限、長者緊急住宿、離院支援及殘疾人士照顧者津貼，以及三項醫管局／中心活動。大興邨、澤豐花園活動的居住條件只適用於該兩項活動；未公布場地不提供地圖。醫管局未公布統一電話的項目按醫院繳費處或病房途徑查詢。

續查另補樂屯聚日間暫顧每小時5.1元及年費21元、大興復康中心基準收費，4間中心指定當季免費認知活動；其他費用與即時名額不推斷。43檔395項本機測試及正式建置通過。
