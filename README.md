# DoDo 長者及照顧者支援

[開啟免費網站](https://lihunglam14-commits.github.io/dodo-care/)

先選需要，再選屋邨及一間中心，才看該中心的活動。可按月份、主題及關鍵字篩選，支援大字、中英文、電話、地圖及離線使用。

2026-10-31依官方當季原冊及11月月刊補入39項活動與預約服務；建生堂、友安、曾榮夫人及胡忠原本空白的活動頁已有內容。15間活動導覽中心中仍有5間未有當期逐項詳情，保留官方頁及查詢電話；不代表中心沒有活動。相同報名安排集中顯示，每項內容、費用、資格及報名日期仍保留。預約服務須先確認時段，活動名額以中心回覆為準。

實際資格、報名、費用、名額及場地，以主辦機構確認為準。DoDo並非政府或服務機構網站，不宣稱活動全部齊全或即時仍有位。

本輪本機69檔607項測試、TypeScript及正式建置通過，並在Chrome手機尺寸操作中心、月份、主題、搜尋及英文版；不等於真手機、讀屏或長者用測。沒有執行GitHub測試CI，只沿既有免費legacy Pages發布。

本分支只含22個靜態產物、README及.nojekyll，沒有私人Excel、開發原始檔或內部研究／核對紀錄。
