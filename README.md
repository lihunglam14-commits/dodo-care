這是供同事及少量用戶試用的臨時 GitHub Pages 網站，不是長期正式託管。`codex/site-current` 只存放 2026-10-09 最新建置的公開靜態網站：屯門服務搜尋、活動資訊及按目前網址產生的清單分享連結；不包含私人 Excel 或工作文件。

此版本無須登入，雲端使用統計已關閉，也不會向 `/api/analytics/events` 送出請求。試用期間如需回饋，請由同事直接收集，不會從此網站自動取得長者的使用資料。

舊的 `chatgpt.site` 網址在香港測試時收到 403；請以以上 GitHub Pages 網址試用。若網站資料有變，須重新建置並更新此分支，網站才會同步更新。
