# DoDo 長者及照顧者支援

[開啟免費網站](https://lihunglam14-commits.github.io/dodo-care/)

第一題提供「津貼或減輕開支」及「活動及認識朋友」。選活動後，先選屋邨及一間中心，再按月份、主題或關鍵字找活動。支援大字、中英文、電話、地圖及離線使用。

活動附官方來源、日期、費用及資格；已開班、候補、尚未接受報名及已截止報名會分開標示。不保證即時有位。富泰及王木豐另附社署公布的項目介紹；推行期不代表個別場次或已接受報名。

富泰、信義健頤、王木豐及信義尊長會仍未有可核實的當期逐項時間表；其他中心亦不宣稱活動已全部齊全。請向中心確認實際資格、費用、報名、名額及場地。DoDo並非政府或服務機構網站。

網站採柔和灰綠暫定配色及一致排版；首頁保留原動畫，改善長者步姿；概念長者中心作標題旁的靜態淡水印，並用於中心入口及中心頁，不進入動畫；人物面部、手掌及道具接點經調整，分類插畫配色較柔和。活動列出名稱、日期、簡介、時間、收費及簡短資格，詳細地點及報名方法按「詳情及報名」查看。短日期靠左，長期間及特大字改上下排列。相同報名安排只列一次，截止及未開放日期仍直接顯示。另可搜尋富泰營養午餐、蝴蝶邨視障復康訓練、視障陪診及殘疾人士登記證，查看資格、收費和申請方法。

本分支只存放公開網站靜態產物，不包含私人Excel或開發原始檔。
